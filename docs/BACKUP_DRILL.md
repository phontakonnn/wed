### ขั้นตอนที่ 4: สั่งตรวจสอบไฟล์สำรอง (`backup:verify`)


- ตรวจสอบความถูกต้องของ Schema, Checksum และ AES-256-GCM objects สำเร็จสมบูรณ์
